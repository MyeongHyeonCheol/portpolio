Problem & Role

Problem

기존 맛집 추천 서비스는 사용자의 개인 선호도와 현재 상황을 충분히 반영하지 못하는 경우가 많았습니다. 또한 광고성 추천이 섞이면서 사용자가 추천 결과를 신뢰하기 어렵고, 오히려 선택 피로도가 높아지는 문제가 있었습니다.

My Role

  • 2인 팀의 팀장으로 프로젝트 방향 조율
  • Next.js, TypeScript 기반 프론트엔드 개발
  • NestJS, PostgreSQL 기반 백엔드 API 구성
  • 사용자 선호도 기반 추천 알고리즘 개발
  • Docker Compose, AWS 기반 실행 및 배포 환경 구성

Story

FoodPick은 사용자가 매번 무엇을 먹을지 고민해야 하는 상황과, 개인 선호도나 현재 위치를 충분히 반영하지 못하는 기존 맛집 추천 방식의 한계를 개선하기 위해 기획한 AI 기반 맞춤형 맛집 추천 서비스입니다. 2인 팀의 팀장으로 참여해 서비스 방향을 정리하고, 프론트엔드와 백엔드 개발을 함께 담당했습니다.

프론트엔드에서는 Next.js와 TypeScript를 활용해 사용자가 음식 카테고리, 위치, 추천 결과를 자연스럽게 확인할 수 있도록 화면 흐름을 구성했습니다. 백엔드에서는 NestJS와 PostgreSQL을 활용해 서비스에 필요한 데이터 저장 구조와 API 흐름을 구성했습니다. 또한 사용자 선호도와 상황을 반영한 추천 알고리즘을 개발해 단순 광고성 노출이 아니라 사용자에게 더 적합한 맛집 정보를 제공하는 방향으로 서비스를 구현했습니다.

Docker Compose를 활용해 개발 및 실행 환경을 구성했고, AWS를 통해 실제 서비스가 접속 가능한 형태로 운영될 수 있도록 배포 환경을 마련했습니다. 프로젝트 결과 학술제에서 우수상을 수상했으며, 최종 팀 순위 3등을 달성했습니다. 현재도 https://foodpick.net/ 주소를 통해 서비스가 운영되고 있습니다.

STAR

Situation

기존 맛집 추천 서비스는 개인 선호도와 상황을 충분히 반영하지 못했고, 광고성 추천으로 인한 피로도가 있었습니다.

Task

사용자가 편하게 이용할 수 있는 UI/UX와 개인화 추천 기능을 갖춘 맛집 추천 서비스를 구현해야 했습니다.

Action

팀장으로 방향을 조율하고, 프론트엔드와 백엔드, 추천 알고리즘, 실행 및 배포 환경을 함께 구성했습니다.

Result

학술제 우수상과 최종 팀 순위 3등을 달성했고, 현재도 서비스가 운영되고 있습니다.
